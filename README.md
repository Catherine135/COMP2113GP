1. Get connected to HKU VPN
2. Open terminal and type in "ssh hxxxxxxx@academy11.cs.hku.hk", then enter password
3. git clone https://github.com/Catherine135/COMP2113GP

5. make clean
6. make
7. ./build/generals_ai
8. Once new version is released, use "git pull" to update the code, then use "make clean" "make" to recompile and run
